ProBis Controller — Zeebe RPC + Camunda REST API

⚠️ User Task operations require Camunda 8 REST API running on port 8080. Basic Zeebe operations (start, message, cancel) work without it.
Variables (JSON)
Dipakai saat Start/Message

Start Process dengan File Attachment

File akan di-upload dan path-nya ditambahkan sebagai variable "attachedFile" ke process instance.

Flow (Collapsible)

1) Receive Order → Start Process
Memanggil POST /rpc/start
2) User Task Ops (Tanpa Tasklist API)
UserTaskKeyNameAssigneePI KeyFormKeyTimestamp
Task Details (Pretty JSON)
Select a task and click "Get Details" to see formatted task information with variables
3) (Opsional) Deploy BPMN dari Path Server
Endpoint /rpc/deploy menerima path file di SERVER (bukan upload dari browser).
4) Upload & Deploy BPMN File
Upload file BPMN dari browser dan deploy langsung ke Zeebe. File akan disimpan di server dalam folder uploads/.
